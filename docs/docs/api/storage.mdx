# Storage

A `SpanStore` is where scan progress persists. The interface is deliberately tiny (OrbitDB-style: one small async contract, swappable backend modules) so writing your own — an IndexedDB store, a cookie store, whatever fits your app — is a handful of lines with no changes needed anywhere else.

## `SpanStore`

```ts
import type {SpanStore} from '@ethereum-radio/indexer';

interface SpanStore {
	load(key: string): Promise<Span[] | undefined>;
	save(key: string, spans: Span[]): Promise<void>;
	clear?(key: string): Promise<void>;
}
```

`key` is entirely caller-owned (e.g. `` `${chainId}:${address}:${topic0}` ``) — this package doesn't prescribe a keying scheme, so you're free to namespace by chain, contract, filter, or however else makes sense for your app.

## `createMemoryStore`

```ts
import {createMemoryStore} from '@ethereum-radio/indexer/storage/memory';

function createMemoryStore(): SpanStore;
```

`Map`-based, no dependency beyond the language itself. The default choice for tests, SSR, Node scripts, or anywhere progress doesn't need to outlive the process. Defensive copies on load/save mean mutating a returned array can't corrupt the store's internal state.

## `createLocalStorageStore`

```ts
import {createLocalStorageStore} from '@ethereum-radio/indexer/storage/local-storage';

function createLocalStorageStore(prefix?: string): SpanStore;
```

Backed by the browser's `localStorage` global — nothing else required. `prefix` (default `'ethereum-radio:spans:'`) namespaces keys so multiple stores in the same origin don't collide.

`JSON` can't represent `bigint` natively, so bigint values (`Span.fromBlock`/`.toBlock`) are round-tripped as `"123n"`-suffixed strings under the hood — transparent to callers, but worth knowing if you ever inspect the raw `localStorage` value directly.

## Writing your own

An IndexedDB or cookie-based store fits the same three-method interface without any change to `Cursor`, `createRadio`, or anything else in this package — an IndexedDB store, for instance, is just an async `get`/`put` wrapped to match `SpanStore`'s shape.
